# 全身 IK 与分段节奏工具

入口：`ue58_three_assets_v2/launch_animation_workbench.py`。
把这个文件拖进 Maya 视口，会安装 **IK Rhythm** 工具架按钮并打开面板。
安装同时写入当前用户的 Maya `.mod` 路径，使保存后的场景能找到求解器插件。
也可在 Python Script Editor 执行：

```python
import runpy
runpy.run_path(r"你的项目路径/ue58_three_assets_v2/launch_animation_workbench.py", run_name="__main__")
```

支持 Maya 2025（PySide6），界面也兼容 PySide2。运行依赖本项目原有的 UE 5.8
PBIK 本机库，首次构建要求见 [native/README.md](../ue58_three_assets_v2/ue_ik_retargeter_maya/native/README.md)。
节奏模块只使用 Python 标准库和 Maya，不需要 SciPy、外部 Python 或子进程。

## 1. 生成与删除全身 IK

1. 选择人体骨架中任一骨骼或蒙皮网格，点击“使用选中骨架”。
2. 设置动画开始、结束和参考帧。常用参考帧为 0，动画范围从 1 开始。
3. 点击“一键生成全身 IK + 控制器动画”。

自动识别双手、双脚、骨盆，具备对应骨链时也生成胸部与头部控制器。
原骨骼动画通道保留，通过隐藏输入骨架与 DG 矩阵节点求解全身 IK。
控制器源动画默认直接烘焙在控制器上；勾选选项后放入独立源动画层。
控制器在世界空间，位移与旋转按整帧记录。移动任一控制器仍会参与全身联动。
参考帧保留，节奏只在指定动画范围内处理。

双手拉扯胸部时，可调整“脊柱 / 肩部稳定强度”（默认 85%）。它在每帧约束
脊柱和肩部对输入姿态的保持程度，不依赖上一帧计算结果，跳帧和倒放也能得到一致结果。
较高数值减少胸部被手部拉动的幅度；复杂动作仍可能需要调整控制器目标或手修。

“膝盖朝向保持”默认 100%。脚部目标限定脚踝的姿态，但单靠脚踝目标不能唯一确定
膝盖绕髋踝连线的朝向，因此全身求解中拉手也可能造成膝盖额外侧摆。
工具在 PBIK 后将腿部弯曲平面保持在当前源动画方向；腿完全伸直时使用参考平面
或脚趾方向。该步骤保留 PBIK 的髋部、脚踝位置和脚部旋转，并保持腿段长度，
不提高腿部刚度、不锁死下蹲。骨盆移动仍会导致膝盖正常弯曲，不能把膝盖当成世界空间固定点。
该效果可单独降低到 0%，旧绑定在刷新面板时自动补上；原有动画曲线不改写。

删除提供两种方式：

- **保留原骨骼源动画**：恢复原始 offsetParentMatrix，移除工具拥有的绑定与效果节点。
- **烘焙当前骨骼结果**：逐帧取最终骨骼姿态，转换为关节本地 TRS，写入独立覆盖动画层
  `AW_BakedSkeleton`，检查转换结果后移除 IK。原骨骼源曲线留在底层，结果层权重设为 0 可恢复源动画。

操作可 Undo，不会自动保存场景。原骨架不会被加入工具的删除所有权列表。
当前场景旧版 `Dance_FullBodyIK` 可被接入，已有控制器、层权重及重点帧标记会保留。

## 2. 书签就是重点 pose

“自动识别全身重点 pose”只分析缓存轨迹的速度低谷、转向和 XYZ 极值，生成
双手、双脚、质心的书签；不改动画、不调用网络或 AI。可设置最小间隔与每部位数量。

“当前帧添加书签”作用于节奏面板勾选的部位；列表支持多选删除，双击跳到该帧。
各部位使用不同颜色。**书签的起始帧是 B**，书签宽度不代表 hold 时间。
可在原生时间轴里移动、删除这些书签，再点击“仅按当前书签重新生成”。
移动过的自动书签按手动书签保留；重新识别也保留手动书签与已有参数。
无书签的部位重建后回到源轨迹，不使用旧的隐藏重点帧列表。其他工具的书签不参与处理。

## 3. 按完整时间段修改节奏

每个 B 根据相邻书签与最大影响半径形成 A→B→C 区间。A、C 是源轨迹固定锚点，
不一定是原始关键 pose。相邻 B 的影响区间不会交叠。曲线即使每帧有 key，
也会作为完整轨迹采样并重建，不只修改 B 的单个切线。

| 参数 | 定义 |
| --- | --- |
| 向左 / 向右 hold | 独立整数帧，可各自为 0。B 是中间标识，蓝色上光标控制左侧，橙色下光标控制右侧。 |
| Hold 强度 | 原生动画层实时混合。0% 使用源动画，100% 在 `[B−左, B+右]` 保持 B，挤压前后过渡时间；中间值混合源姿态与完整 hold 结果。 |
| 缓冲过渡段占比 | 占 A→hold 起点的可用时间百分比，靠近到达端。 |
| 预备过渡段占比 | 占 hold 终点→C 的可用时间百分比，靠近出发端。 |
| 空间幅度 | 原本段轨迹弧长的百分比，不是固定厘米数。缓冲按到达方向超越后回收，预备先逆出发方向移动。 |
| 缓冲 / 预备独立强度 | 各自动画层的实时权重，分别缩放空间效果，不改变 hold 强度。 |
| 部位总强度 % | 直接控制该部位总强度动画层的 weight，并同时驱动三项效果的最终权重。0% 为源动画。 |
| 旋转同步变速 | 按相同时间映射重取旋转；空间反向脉冲只作用于位移。 |

时间占比按可用过渡段计算并取整，缓冲和预备均排除完整 hold 区间及其端点。
若可用段只有一帧，没有内部整数采样点，反向脉冲不会出现；增大占比或影响范围即可。
实际 hold 在相邻书签过近或片段边界时会被限制，避免改变 A、C。
双侧 hold 都为 0 时不重映射时间；缓冲和预备仍可独立开启。

总强度、Hold、缓冲、预备都提供横向滑杆与百分比输入框，拖动即可实时预览，
无需点击应用，也不重新生成姿态曲线。每次完整拖动可用一次 Undo 撤销。
未选中书签时，三项独立强度作用于勾选部位的所有 B；选中书签时只调整这些 B。
各 B 的独立强度保存为稀疏、阶梯型原生权重曲线，部位总强度再统一缩放。

时长、过渡段占比和空间幅度属于曲线形状参数，修改后点击“应用时长 / 幅度并重建节奏”。
未选中书签时应用到勾选部位的所有 B。选中书签后，面板载入第一个 B 的参数，
应用按钮只更新所选 B，并重建它们所属部位。
“仅按当前书签重新生成”保留每个 B 的独立设置。
点击部位旁“曲线”可打开 Maya Graph Editor。

姿态结果只生成整帧 key。强度滑杆只更新动画层权重；只有点击应用才重新生成姿态曲线，
不在拖动或播放时烘焙，也不会在释放滑杆时把播放头拉回拖动起始帧。
Hold 使用 **By Layer 四元数覆盖层**，缓冲和预备各用一个位移叠加层。
旋转曲线使用最短路径四元数插值。
这两项共同修复中间层权重下的手腕翻转；仅做 Euler Filter 或只检查 0/100% 权重不足以覆盖此问题。
重新生成时先切换到独立 Euler 通道写入，再统一转回四元数，避免 Maya 的轴同步写 key
把其他旋转轴归零。验证包含连续两次生成后的整段旋转混合。

手工修改基础控制器动画后，点击“更新控制器源动画缓存”，再重新生成。
缓存存入绑定根节点并跟随场景保存，不依赖当前磁盘场景路径。
脚部低位重点 pose 的反向脉冲投影到水平面，并限制在该段源踝关节最低高度之上；
这不是鞋底网格碰撞检测。

## 验证

纯 Python：

```text
python -m unittest discover -s test -p test_animation_workbench_engine.py -v
```

独立 Maya 2025（只操作测试夹具，不连接当前场景）：

```text
"C:/Program Files/Autodesk/Maya2025/bin/mayapy.exe" test/animation_workbench/validate_maya.py
```

覆盖直接控制器源动画 / 独立源层、原骨骼源曲线保留、含关节定向与外部缩放父级的
初始姿态一致性、书签识别不写曲线、手动增删、整帧 key、0/25/50/60/75/100% 旋转混合、
保存重开缓存、两种删除与烘焙结果一致性，以及无关书签保留。
还覆盖拉手、抬脚、质心下移时膝盖平面保持，以及髋部和脚端求解结果不变。
实时权重测试覆盖三项效果独立开关、混合强度、部位总强度、所选 B 的单独权重、
一次撤销恢复元数据，以及拖动时姿态曲线完全不变。

当前 353 帧场景验证：五个部位在六档混合权重及选定半帧处的四元数误差均小于
0.00006 度；393 条原始骨骼曲线的时间和值与原保存文件完全一致。
85% 胸部稳定下，胸部相对源动画的位置修正二阶差分 RMS 从 1.633 降到 0.689，
下降 57.8%。这是本动作的抖动测量结果，不代表所有动作都能完全消除抖动。
